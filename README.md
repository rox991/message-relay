# message-relay
Python payload that sets up a simple server on the victim's device, allowing you to send messages 
🔧 How to Use:
  #On the victim's device:
    *Run the server script above.
    *It will wait for a connection on the specified port.
  #On your Kali Linux machine:
    *Run the client script above.
    *Enter any message you want to send to the victim's device.
    *The message will be displayed on the victim's screen.
